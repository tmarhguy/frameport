[.lead]
This manual is the detailed technical reference for FramePort: HDMI and
USB video capture inside VS Code. It describes architecture, interfaces,
programming model, verification, implementation, and performance in one
numbered, navigable document.

.Live capture inside VS Code — click through to the full clip.
image::frameport-demo.gif[FramePort live capture demo in VS Code,align="center"]

The full recording is
https://raw.githubusercontent.com/tmarhguy/frameport/main/media/screenshots/frameport-demo.mp4[frameport-demo.mp4].

The concise project overview stays in the repository
link:../README.md[root README].
Executable sources under `src/` win over this prose when they disagree;
`docs/DEVELOPMENT.md`, `docs/DESIGN.md`, `docs/PUBLISHING.md`, and
`CHANGELOG.md` are the current facts. Dated entries under `docs/log/`
are history and never authoritative for current status.

[source,bash]
----
# Build this manual locally (requires Asciidoctor, no Node.js)
make docs
# Output: build/docs/index.html
----
