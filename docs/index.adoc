FramePort is an extension for VS Code. It opens a live HDMI or USB video feed in an editor tab, so a board's display sits next to the code that drives it. On a Mac it can also open the iPhone camera, so the preview is you, or Desk View, the overhead camera. It can save a PNG screenshot or a silent MP4.

The extension is published on https://open-vsx.org/extension/tmarhguy/frameport[Open VSX]. Where this manual and `src/` disagree, the source wins.
